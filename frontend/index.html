REST API Reference

Authentication & Protected Endpoints

All endpoints adhere to REST conventions, enforce JSON payloads, validate inputs, and provide unified error structures.

POST /api/auth/register Public

Registers a new user account. Hashes password using bcrypt with 12 rounds.

Request Body (JSON):
{
  "username": "johndoe",       // required, 3-30 chars, alphanumeric
  "email": "john@example.com", // required, valid email format
  "password": "StrongPassword123!", // required, min 8, lower/upper/num/symbol
  "fullName": "John Doe",      // optional
  "role": "user"               // optional: 'user' | 'admin'
}
Success Response (201 Created):
{
  "success": true,
  "message": "User account registered successfully.",
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": { "id": "...", "username": "johndoe", "email": "john@example.com", "role": "user" }
}
POST /api/auth/login Public

Authenticates credentials, updates last login, issues JWT and sets HttpOnly cookie.

Request Body (JSON):
{
  "identifier": "john@example.com", // email or username
  "password": "StrongPassword123!"
}
Success Response (200 OK):
{
  "success": true,
  "message": "Login successful.",
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": { "id": "...", "username": "johndoe", "email": "john@example.com", "role": "user" }
}
POST /api/auth/logout Private (JWT)

Invalidates session, records token in blacklist database, and clears HttpOnly cookie.

Success Response (200 OK):
{
  "success": true,
  "message": "Successfully logged out and session revoked."
}
GET /api/auth/me Private (JWT)

Returns current authenticated user details from token verification.

GET /api/protected/dashboard Private (JWT)

Returns protected application dashboard data, session timestamps, and system statistics.

PUT /api/protected/profile Private (JWT)

Updates user's full name and biography.

POST /api/protected/change-password Private (JWT)

Verifies current password and securely hashes and saves the new password.

GET /api/protected/admin/users Admin Only

Role-based access control (RBAC). Returns list of all registered accounts. Restricted to 'admin' role.
